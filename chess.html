Comment utiliser l'application ?

📚 Le Tableau de Bord

Votre tableau de bord conserve l'historique de vos révisions. Pour chaque répertoire, vous pouvez voir vos chapitres, le nombre de coups, et votre taux de réussite.

  • Vitesse & Cache : L'application mémorise les données des études pendant 1 heure. Cela permet une navigation instantanée.
  • Synchronisation : Si vous avez modifié votre étude sur Lichess, cliquez sur le bouton "Synchroniser" en bas d'un répertoire pour forcer la mise à jour des données.
  • Badge "MAJ" : Si une modification est détectée (nouveaux coups), un badge "MAJ" apparaît et votre pourcentage de réussite est ajusté automatiquement.
  • Suppression : Vous pouvez nettoyer votre historique via le bouton "Supprimer" dans les détails d'un répertoire.

🔗 Charger une étude

Copiez/collez l'URL d'une étude Lichess publique. Vous pouvez aussi utiliser l'URL d'un chapitre spécifique. Note : Les études doivent être "Publiques" ou "Non répertoriées" sur Lichess.

🎯 Modes d'entraînement

  • Mode Découverte : Idéal pour apprendre. Une flèche verte indique le prochain coup. Les erreurs ne sont pas comptabilisées.
  • Mode Révision : Testez vos connaissances sans aide. Les erreurs impactent votre taux de réussite. L'entraînement se termine une fois toutes les variantes validées.

💡 Fonctionnalités en jeu

  • Échiquier Sticky : Sur mobile, l'échiquier reste fixé en haut pour ne jamais le perdre de vue.
  • Solution : Affiche la flèche d'aide (compte comme une erreur en mode Révision).
  • Notes : Affiche les commentaires PGN importés de Lichess.
  • Navigation : Utilisez les flèches ⬅️ ➡️ ou cliquez directement sur les coups dans la notation pour naviguer.
