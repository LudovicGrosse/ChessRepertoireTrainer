Guide d'utilisation

🔗 Connexion Lichess & Études

Allez dans les Paramètres (⚙️) pour connecter votre compte Lichess en un clic. Cela vous permet d'importer automatiquement vos études privées. Vous pouvez également importer n'importe quelle étude publique en collant simplement son URL.

📊 Gestion de vos Répertoires

Vos ouvertures sont organisées par couleur (Blancs/Noirs) dans votre tableau de bord.

  • Indicateur de Mise à Jour : Un point orange apparaît si une étude a été modifiée sur Lichess depuis votre dernier entraînement.
  • Synchronisation : Cliquez sur le bouton de synchronisation d'un répertoire pour récupérer les derniers coups ajoutés depuis Lichess.
  • Suivi de Réussite : Le pourcentage de réussite vous aide à cibler les chapitres que vous maîtrisez le moins.

🎯 L'Entraînement

  • Mode Découverte : Suivez les flèches grises sur l'échiquier pour apprendre vos lignes sans pression. Idéal pour une première lecture.
  • Mode Révision : Testez votre mémoire ! L'ordinateur joue les coups de votre adversaire et vous devez trouver vos coups. Vos erreurs sont enregistrées pour calculer votre score de réussite.

💡 Astuces en cours de partie

  • Navigation : Utilisez les flèches directionnelles de votre clavier (◀ / ▶) pour naviguer rapidement dans les variantes.
  • Solution : Un trou de mémoire ? Cliquez sur "Solution" pour afficher le coup attendu (attention, cela compte comme une erreur en mode Révision !).
  • Notes & Commentaires : Le bouton "Notes" affiche vos propres commentaires Lichess associés à la position actuelle.
  • Analyse Lichess : Cliquez sur "Analyse" pour ouvrir directement la position actuelle dans le moteur d'analyse de Lichess.
