Guide d'utilisation

🚀 Démarrage Rapide

Importez n'importe quelle étude Lichess publique en collant son URL. L'application récupère automatiquement tous les chapitres.

📊 Gestion du Répertoire

Vos ouvertures sont classées par couleur dans votre historique pour un accès rapide.

  • Synchronisation : Mettez à jour votre répertoire en un clic si vous avez ajouté des coups sur Lichess.
  • Indicateur MAJ : Un badge orange vous signale les chapitres ayant été modifiés sur Lichess depuis votre dernière visite.
  • Suivi de réussite : Visualisez votre taux de succès par chapitre pour identifier vos points faibles.

🎯 Modes d'Entraînement

  • Mode Découverte : Idéal pour apprendre une ligne. Suivez la flèche d'aide grise sans pression.
  • Mode Révision : Testez votre mémoire. L'application joue les coups adverses et enregistre vos erreurs pour calculer votre score.

💡 Fonctionnalités Utiles

  • Solution : En cas d'oubli, affichez le coup attendu (compte comme une erreur en révision).
  • Navigation : Utilisez les flèches du clavier ou cliquez sur la notation pour explorer les variantes.
  • Analyse Lichess : Basculez vers l'outil d'analyse Lichess à tout moment pour approfondir une position.
